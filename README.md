# الميديا باير · Zaki Media Buyer

مدير إعلانات ميتا للدفع عند الاستلام. القرار بيصير على **حقيقة الطلبات من الـ OMS** (مؤكد ومُسلَّم)، مش على أرقام ميتا لحالها. الأمان تلقائي (إيقاف وتخفيض)، وأي صرف أو إنشاء بموافقتك من الموقع، وأبداً من تيليجرام.

| وين | شو |
|---|---|
| الموقع | https://mediabuyer.zakiai.io |
| الكود | https://github.com/iahmed30004000-wq/zaki-mediabuyer |
| التشغيل | كوليفاي ← مشروع «Zaki Media Buyer» ← production ← الخدمة `mediabuyer` (الموقع + العامل + قاعدة البيانات) |
| المواصفات | `docs/SPEC.md` · التقدم `docs/PROGRESS.md` · القرارات `docs/DECISIONS.md` · الفحص الشامل `docs/FULL_CHECK.md` |

## الاستعمال اليومي — خمس أماكن

| المكان | السؤال اللي بيجاوبه |
|---|---|
| **اليوم** | شو لازم أعمل هلأ؟ موافقاتك · قرارات الأمان اللي صارت · الأفضل والأسوأ · صحة المصادر |
| **الإعلانات** | كيف ماشية بالحقيقة؟ الحملات · المنتجات · الاختبارات · زر «＋ إطلاق» |
| **الإبداعات** | الفيديوهات من الاستلام للرفع، والمكرر، وفحص السياسات |
| **القرارات** | بانتظارك · صار تلقائي (وكل وحدة إلها «رجّع») · سلّم التكبير وليش ما كبّر |
| **التقارير** | الصباحي والأسبوعي والشهري · خطة الأسبوع · سجل الدروس · صحة البيانات · سلامة الحسابات |

والإعدادات لكل شي بينضبط مرة: الربط · السقوف · المنتجات · المستويات · الوكلاء · المظهر.
**المستشار** زر بكل صفحة: بيجاوب من أرقامك، وبيعرض تحت الجواب الأرقام اللي جاوب منها.
**على الجوال:** افتح الموقع بكروم ← «إضافة للشاشة الرئيسية». بينفتح كتطبيق، وبلا نت آخر نسخة من الصفحات (وآخر تقرير) بتنفتح. الموافقات والإيقاف بدهم نت دايماً.

## الإيقاف الكامل

الزر الأحمر فوق بكل صفحة: بيوقّف كل حملات حساب، أو كل الحسابات، بتأكيدين، وبينكتب بالسجل. من تيليجرام كمان: «اوقف» بيوقّف بس — أي شي بيصرف بيرفضه وبيبعتلك رابط الموقع.

## تغيير المستوى (لكل حساب إعلاني)

الإعدادات ← «القواعد والمستويات» ← اضغط المستوى.

| المستوى | شو بيعمل لحاله |
|---|---|
| 0 مستشار | ولا شي — اقتراحات بس |
| 1 حارس (البداية) | بيوقف الخاسر وبيخفّض. أي زيادة صرف بموافقتك |
| 2 مكبّر محدود | متل الحارس، وكمان بيكبّر الرابح +20% كل 48 ساعة ضمن السقف (حد +50% بالأسبوع) |
| 3 مدير | مطفي بهالمرحلة |

- المستوى 2 بينفتح بعد **أسبوعين** من أول قرار على الحساب. إذا ضغطته قبل، بيقلك قديش ضايل.
- النزول مسموح دايماً.
- حساب عليه تنبيه سلامة (مقيّد · دفع · توكن منتهي) بيشتغل على **صفر** لحاله لحد ما تنحل.

## الإعدادات والفريق

- **السقوف** (يومي وشهري لكل حساب) و**التوزيع** و**أرقام المنتجات** و**سقف كل منتج** و**رموز الصفحات** و**صفحات الهبوط**: كلها من الإعدادات، للمالك بس، وكل تغيير بينكتب بالسجل وإله نسخة بترجعلها.
- **عضو جديد:** الإعدادات ← «الفريق والتدقيق» ← الإيميل والاسم والدور ← «ادعُ». بيطلعلك رمز **مرة وحدة** — ابعته للعضو بإيدك. هو بيفتح الموقع ← «عندي رمز دعوة» ← إيميله والرمز وكلمة سر بيختارها. الرمز بينفع 72 ساعة ومرة وحدة.
- **نسي كلمة السر:** «رمز جديد» جنب اسمه. **بدك توقفه:** «أوقف» — كل جلساته بتنتهي فوراً.
- **السجل** تحت الفريق: مين (إنسان · قاعدة · وكيل) عمل شو، على شو، قبل وبعد، ومتى.

- **شبكة الأمان على ميتا:** الإعدادات ← السقوف ← «جهّزها» جنب الحساب. بتحط سقف صرف للحساب عند ميتا (الشهري + 10%) وقاعدة جوّا ميتا بتوقف أي مجموعة صرفت ضعف هدف الطلب اليوم بلا نتيجة — بتشتغل حتى لو نظامنا وقف. بتستنى موافقتك بـ «القرارات»، وأول كل شهر بيوصلك طلب تصفير السقف.
- **الاستيراد:** الإعدادات ← «الاستيراد والتصدير» ← ملف مدير الإعلانات اليومي على مستوى الإعلان. بتشوف الأعمدة والمعاينة قبل ما يدخل شي، ونفس الملف مرتين بينحسب مرة.

## ربط حساب ميتا (P0.4) — خطوة خطوة

1. **developers.facebook.com** ← أنشئ تطبيق من نوع Business، واربطه بمدير الأعمال تبعك.
2. **business.facebook.com ← الإعدادات ← مستخدمو النظام** ← أنشئ مستخدم نظام (Admin)، وأعطيه الحسابات الإعلانية والصفحات والبكسل اللي بدك ياهم بس.
3. «إنشاء رمز» للتطبيق بالصلاحيات: `ads_read` · `ads_management` · `business_management` · `pages_show_list` · `pages_read_engagement` · `pages_manage_ads`.
4. **كوليفاي** ← الخدمة `mediabuyer` ← Environment Variables ← حط الرمز بـ `META_SYSTEM_USER_TOKEN` بإيدك. ولا مرة بالمحادثة ولا بملف بالمستودع.
5. غيّر `MOCK_MODE` لـ `0` ← «Restart». الموقع بيسحب الحسابات والحملات والأرقام بأول نص ساعة.
6. **`META_WRITE_MODE` بيضل `dry_run`**: كل قرار بيسجّل شو كان رح يبعت وما بيبعت. بيصير `live` بس بعد ما ينجح الفحص على **حساب إعلاني تجريبي** (P0.5).

باقي الروابط بنفس الطريقة (كلها بكوليفاي، كلها بإيدك):

| الربط | المتغيّرات |
|---|---|
| الـ OMS (P0.3) | `OMS_BASE_URL` · `OMS_TOKEN` |
| تيليجرام (P0.7) | `TELEGRAM_BOT_TOKEN` · `TELEGRAM_OWNER_CHAT_ID` · `TELEGRAM_ALLOWED_CHAT_IDS` |
| درايف (P0.6) | `GOOGLE_SERVICE_ACCOUNT_JSON` · `DRIVE_PRODUCTS_FOLDER_ID` |
| الموديل الداخلي | `INTERNAL_MODEL_BASE_URL` · `INTERNAL_MODEL_NAME` |
| موديل خارجي (اختياري) | `EXTERNAL_MODEL_BASE_URL` · `EXTERNAL_MODEL_KEY` · `EXTERNAL_MODEL_NAME` |
| أحداث التحويل | `META_DATASET_ID` (اختياري) · `CAPI_TEST_EVENT_CODE` لأول تجربة بأداة Test Events |

بالإعدادات ← «الربط» بتشوف شو انربط وشو لأ. ولا مفتاح بينعرض بالموقع أبداً.

## التحديث

تلقائي بالكامل:

1. الشغل بينرفع على فرع `feat/structure-and-themes`، وبينفتح طلب دمج لـ `main`.
2. جيت هب بيفحص: الأنواع · الاختبارات · الأسرار · بناء الصورة وتشغيلها.
3. إذا نجح، **بيدمج لحاله**، وبينشر الصورة، وبيبلّغ كوليفاي.
4. الدورة ما بتنجح إلا لما الموقع يرد بالنسخة الجديدة نفسها.

**تعرف شو النسخة الشغّالة:** https://mediabuyer.zakiai.io/api/health ← الخانة `version`.

| شو بدك ترجّع | كيف |
|---|---|
| **قرار على ميتا** (إيقاف · ميزانية · إطلاق) | «القرارات» ← البطاقة ← **رجّع**. بيعمل تغيير جديد معاكس، والقديم بينعلّم «انرجع». الإطلاق بيرجع بإيقاف كل اللي انعمل، بلا حذف |

## النسخ الاحتياطي والاسترجاع

- **تلقائي كل يوم الساعة 2:30** (بتوقيت عمّان): كل الجداول ← `/app/storage/backups/<التاريخ>/` على قرص الخدمة، وبيضل آخر 14 يوم.
- **نسخة هلأ:** كوليفاي ← `mediabuyer` ← `app` ← Terminal:
  ```
  npm run db:backup
  ```
- **الاسترجاع** (لقاعدة فاضية بس — بيرفض قاعدة فيها بيانات):
  1. أوقف `worker`.
  2. بالـ Terminal تبع `db`: `dropdb -U mediabuyer mediabuyer && createdb -U mediabuyer mediabuyer`
  3. «Restart» لـ `app` (بيعمل الجداول فاضية).
  4. بالـ Terminal تبع `app`: `npm run db:restore -- /app/storage/backups/<التاريخ>`
  5. بيتأكد إنه كل جدول عدده مطابق للنسخة، بعدين شغّل `worker`.
- **تجربة الاسترجاع** (على الجهاز، ولا بتلمس القاعدة الحقيقية): `npm run check:backup`.

## على جهازك (للتطوير)

النظام لحاله: مجلده، وقاعدة بياناته (`mediabuyer-db` على 5450)، والموقع على 3140.

```
docker compose up -d          # قاعدة البيانات
npm install
npx prisma migrate deploy
npm run dev                   # الموقع على http://localhost:3140
npm run worker                # العامل (السحب · القواعد · التقارير · النسخ)
```

**الإيقاف:** `Ctrl+C` للموقع والعامل، و `docker compose stop` للقاعدة.
`.env` بالمجلد (مش بالمستودع): `MOCK_MODE=1` بيشغّل كل الشاشات على بيانات تجريبية.

| الأمر | شو بيعمل |
|---|---|
| `npm test` · `npx tsc --noEmit` | الاختبارات والأنواع (قبل أي رفع) |
| `npm run check:full` | **الفحص الشامل** (الـ SPEC 17.4) كله، وبيكتب النتيجة بـ `docs/FULL_CHECK.md` |
| `npm run demo:pipeline` | بيانات تجريبية من ميتا والـ OMS الوهميين |
| `npm run check:backup` | نسخة ← استرجاع بقاعدة فاضية ← مقارنة كل جدول |

## القواعد اللي ما بتنكسر

- الكود بيحسب كل رقم. الوكلاء بيفسّروا ويكتبوا بس، وما حدا منهم بيلمس ميتا ولا بيشوف توكن.
- كل تغيير على ميتا = ChangeSet: اقتراح ← تجربة ← موافقة ← تنفيذ ← تحقق ← متابعة ← رجوع.
- كل حملة وإعلان بينشأ **موقّف**، وبيتفعّل بس بعد ما ينقرأ من ميتا ويطابق القالب حقل حقل.
- ولا بيانات زبون (اسم · هاتف · عنوان) لأي موديل ولا بأي سجل. الهاتف بيمر بكود أحداث التحويل بس، بيتشفّر وبينرمى.
- الأحمر بالواجهة للخطر بس.
