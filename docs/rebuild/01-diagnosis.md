## 3. شو تعلّمنا من العيّنة

العيّنة مفهومة من أول نظرة، وهاي أسبابها — وكل سبب صار قاعدة بالخطة:

| اللي بالعيّنة | القاعدة بالموقع الجديد |
|---|---|
| عدّادات فوق: كم مهمة · شغّالة · مرة وحدة · بتخلص لحالها · خلصت | كل شاشة قائمة بتبدأ بعدّاداتها |
| «كيف تقرا الملف» بسطرين | كل مكان إله سؤال واحد تحت عنوانه |
| عمودين: إعلانات · فريق وتشغيل | المجالين هم محور الموقع كله (مكانين + فلتر بكل قائمة) |
| كل مهمة برقم، وفروعها 1.1 · 1.2 | الرقم جزء من المهمة، وبتحكي فيه مع Claude («ألغي 7 و11.3») |
| بطاقة المهمة: الموعد · بتشتغل من · من وين إجت · بتلمس · بتحكي مع | نفس الحقول الخمسة بصفحة المهمة |
| ملاحظة + توصية + «قرارك: خلّيها / ألغيها» | كل توصية بتصير قرار بـ «بانتظارك» |
| رسمة اليوم: إيمتى بتشتغل كل مهمة، وأزحم وقتين | «خط اليوم» بالرئيسية وبتبويب «اليوم» |
| رسمة «التعديلات على جولة الليل» | الأوامر السارية بتظهر على المهمة اللي بتأثّر عليها |
| ورقة القرار بآخر الملف | «ورقة القرار»: كل المهام والفروع بجدول، وبتنبعت مرة وحدة |
| أربع ألوان حالة بس | خمس ألوان بمعنى ثابت (زدنا الأحمر للخطر) |
| «نسخة للطباعة» | كل قائمة وتقرير إله نسخة طباعة A4 |
| أبيض · كحلي · خط ذهبي تحت العناوين | هوية الشكل الجديد (`03`) |
