# 07 — المراحل: أوامر الشغل للبنّاء (P0–P12)

> لمين: النموذج اللي بيبني (Claude Sonnet 5.5، effort عالي). **مرحلة وحدة بالجلسة.**
> قبل أي مرحلة: `docs/rebuild/README.md` لازم يكون مكتوب فيه «☑ معتمدة». لو مكتوب «☐ لسا»: وقّف وقول للمالك.

## قواعد البنّاء (اقراها كل جلسة)

1. **مرحلة وحدة، بالترتيب.** ما تبدأ مرحلة قبل ما اللي قبلها تندمج وCI يخضرّ والإنتاج يتحدّث. ما توسّع المرحلة: اللي مش مكتوب فيها مش إلك.
2. **اقرا قبل ما تكتب:** `CLAUDE.md` ← `docs/rebuild/README.md` ← هالقواعد ومرحلتك ← ملفات المواصفات المذكورة بمرحلتك ← نموذج الشاشة (`docs/rebuild/mockups.html?only=<id>`).
3. **ما بتنلمس** إلا لو مرحلتك قالت بالحرف: ملفات `src/core` الموجودة · أسماء ومدخلات أدوات `/mcp` الموجودة · `/api/v1/*` · `/api/vidpattern/*` · `/api/telegram/webhook` · `/api/health` · خدمة التغييرات (`src/server/changes.ts`) · قفل ميتا (`src/core/readiness.ts`, `src/meta/write.ts`) · المصادقة والتدقيق · سلوك مهام الـ worker.
4. **الهجرات إضافية بس:** عمود اختياري أو بقيمة افتراضية، أو جدول جديد. ولا `DROP` ولا `RENAME` ولا تغيير نوع — حتى بـ P12.
5. **الشاشة من العدّة بس** (`src/components/ui`): ولا `<button>` خام، ولا مقاس نص برّا الخمسة، ولا لون برّا التوكنات، ولا زخرفة. `npm run ui:baseline` لازم ينزّل الأعداد أو يثبّتها.
6. **ولا معادلة بالواجهة، ولا رقم مخمَّن.** كل رقم من loader أو دالة نقية مختبَرة بـ `src/core`. الناقص «—».
7. **الاستبدال على مراحل:** ابنِ الجديد، بدّل العنوان، حوّل القديم (redirect). الملف القديم اللي ما عاد مستعمل بينحذف بـ P12 مش قبل — إلا لو مرحلتك قالت.
8. **الكلام عربي عامي بسيط.** الممنوعات وبدايلها بـ `03-look.md` §8. الكود والحقول إنجليزي.
9. **الريبو عام:** ولا رقم حقيقي، ولا اسم موظف، ولا مفتاح — بالكود ولا بالاختبارات ولا بالدوكات. `node scripts/scan-secrets.mjs` قبل كل commit.
10. **فحوصات كل مرحلة** (كلها لازم تنجح قبل الـ PR):
    ```bash
    npx tsc --noEmit
    npm test
    node scripts/scan-secrets.mjs
    npm run build
    npm run demo:mcp
    ```
    + فحوصات القبول الخاصة بمرحلتك + فحص بالمتصفح على **375×812** و **1280×800**، بالنسخة المحلية بالوضع الحقيقي (`MOCK_MODE=0 AUTH_REQUIRED=1` بحساب مؤقت بينحذف بعدها — الطريقة بملف الذاكرة «windows-dev-and-ui-check-quirks»). فحص الجوال على `npm run build && npm run start` مش على `dev`.
11. **لو الخطة والكود تعارضوا، أو شي مش واضح:** اكتبه بـ `docs/rebuild/NOTES.md` (التاريخ · المرحلة · السؤال · شو اخترت وليش) واختار **الأحفظ**: الأقل تغييراً، واللي ما بيكسر عقد ولا بيحذف شي. ما تخمّن.
12. **آخر كل مرحلة:** حدّث صف المرحلة بـ `docs/PROGRESS.md` (حالة وحدة من الأربعة) · زيد قرار بـ `docs/DECISIONS.md` لو أخدت قرار · ادمج (PR ← CI) واستنى `/api/health` يعرض النسخة الجديدة.
13. **التقرير للمالك بالعربي:** شو انعمل · كيف انفحص · شو ما انعمل أو ما انفحص. بلا تجميل.
