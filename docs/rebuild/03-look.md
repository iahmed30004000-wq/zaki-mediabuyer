# 03 — الشكل والسلاسة

> المرجع البصري: `mockups.html` قسم `#kit`. القيم هون والقيم بـ `:root` بالنماذج لازم يتطابقوا؛ لو اختلفوا، **هاد الملف هو الصح**.

## 1. الهوية بثلاث جمل

**ورق أبيض، حبر كحلي، خط ذهبي** — من ستايل «خريطة المهام المجدولة».
الكحلي للكلام والأزرار الأساسية. الذهبي للإشارة بس (الخط تحت العنوان، التبويب النشط، رقم المهمة، حلقة التركيز) وأبداً مش لنص ولا لتعبئة زر بالفاتح.
ولا زخرفة: لا بلاط ولا صور ولا شرايط ولا تدرّجات ولا ظلال تقيلة.

- خلفية الشارة = اللون نفسه بشفافية 10–12% (`bg-ok/10 text-ok`). ما في توكنات `*-bg`. (النماذج كاتبة قيم `--ok-bg` جاهزة لأنها HTML ثابت.)
- رقم المهمة والشعار: مربّع كحلي ثابت `#1B2A4A` برقم ذهبي `#F2B705` بالثيمين (بالداكن المربّع `#0B1220`). هاد الاستثناء الوحيد لقيمة مكتوبة، وبينحط بمكوّن واحد (`JobNumber`, `BrandMark`).
- كل زوج (نص/خلفية) لازم يعدّي فحص التباين الموجود (`tests/themes-palettes.test.ts`). لو زوج فشل: غمّق لون النص درجة. ممنوع تغيّر معنى لون.
- قيم الأسلوب: `radius-card` = `14px` · `shadow-card` = `0 1px 2px rgb(16 24 40 / 0.04)` · `font-display` = نفس خط النص.

التنفيذ: `THEME_KEYS = ["zaki", "zaki-dark"]` بـ `src/lib/themes/registry.ts` (`themeOf()` أصلاً بيرجّع الافتراضي لأي قيمة قديمة، فكوكيز «iznik» وأخواتها بتتحوّل لحالها). الثيمات الأربعة القديمة وملفات الزخرفة (`src/components/theme/{art-slot,theme-decor,door-shell,decor-visibility}.tsx`, `decor.css`, `public/brand/*` غير الشعار) بتنشال بـ P2 (الاستعمال) و P12 (الملفات).

## 3. الخط والمقاسات

- **خط واحد: Cairo** لكل شي (عناوين ونص وأرقام)، بأوزان 400 · 600 · 700 · 800، عن طريق `next/font/google` بمتغيّر `--font-cairo`. `IBM Plex Sans Arabic` بيضل احتياط بالـ stack. `Reem Kufi` بينشال.
- **خمس مقاسات بس**، وبتنكتب بـ `tailwind.config.ts` كـ `fontSize` (بتستبدل الافتراضي، فأي مقاس تاني ما بيشتغل أصلاً):

| الصنف | المقاس / ارتفاع السطر | وين |
|---|---|---|
| `text-xs` | 12 / 18 | الشارات، التسميات، وقت، نص مساعد. **ولا نص أصغر من هيك** |
| `text-sm` | 14 / 22 | نص القوائم والجداول والأزرار |
| `text-base` | 16 / 26 | النص الأساسي وعناوين البطاقات (16/800) |
| `text-xl` | 20 / 28 | عنوان الصفحة والقسم |
| `text-3xl` | 28 / 36 | الرقم الكبير بالبلاطة |

- الأرقام دايماً لاتيني، `tabular-nums`، وباتجاه LTR (المكوّن `Num` الموجود بيضمنها).
- الأوزان: 400 نص · 600 تسمية/رابط · 700 زر/شارة · 800 عنوان/رقم.

## 4. المسافات والزوايا

شبكة 4px. حشوة البطاقة 16. بين البطاقات 12. بين الأقسام 20 (جوال) / 24 (كمبيوتر). حشوة الصفحة 16 (جوال) / 24 (كمبيوتر). الزوايا: بطاقة 14 · عنصر تحكّم (زر، خانة) 10 · شارة 999 · شريحة 6.

## 5. الأزرار

**مكوّن واحد** `src/components/ui/button.tsx`. ولا `<button>` خام برّا `src/components/ui/`.

| الخاصية | القيم |
|---|---|
| `variant` | `primary` (تعبئة `accent`) · `secondary` (بطاقة بخط `border`) · `ghost` «هادي» (نص بس) · `danger` (تعبئة `danger`) |
| `size` | `lg` 48px (قرارات الجوال وأزرار الصفحة الأساسية) · `md` 40px (الافتراضي) · `sm` 32px (جوّا الجداول عالكمبيوتر بس؛ عاللمس بيصير 40 لحاله: `h-8 max-md:h-10`) |
| `loading` | دوّارة مكان الأيقونة، النص بيضل، والزر مقفول |
| `block` | عرض كامل |
| `confirm="متأكد؟"` | خطوتين جوّا مكان الزر نفسه («متأكد؟ أيوه / لا»، بيرجع لحاله بعد 4 ثواني). لأي شي ما بيرجع |

ومعه: `IconButton` (40×40، 44 عاللمس، `aria-label` إجباري، `tone="danger"` للإيقاف الكامل) و `ButtonLink` (رابط بنفس الشكل).

قواعد الأزرار:
1. **زر أساسي واحد** بكل بطاقة/شاشة. الباقي ثانوي أو هادي.
2. الأساسي دايماً أول واحد (يمين بالعربي)، وبنفس الترتيب بكل مكان: **وافق · ارفض · أجّل**.
3. الزر كلمة أو كلمتين بفعل: «وافق»، «ابعت»، «شغّلها هلأ». ولا «تأكيد» ولا «موافق» ولا «إرسال».
4. الأحمر للخطر بس: الإيقاف الكامل، الحذف الناعم، الرفض النهائي. «ارفض» العادي ثانوي مش أحمر.
5. الزر اللي ما بيقدر يشتغل **ما بيظهر**، أو بيظهر مقفول ومعه سبب عند المسّ. ولا زر بيردّ «بالوضع التجريبي».
6. الحالات كلها مرسومة: عادي · hover · مضغوط (`scale(.98)`) · تركيز (حلقة ذهبية 3px) · مقفول (45%) · عم يشتغل.
7. أربع أزرار بالكتير بصف. الأكتر بقائمة «⋯».

## 7. قواعد السلاسة

1. **المحتوى أول:** بين الهيدر وأول محتوى صف تحكّم واحد بالكتير (تبويبات **أو** مبدّل).
2. **فعل أساسي واحد** بكل شاشة وكل بطاقة.
3. **مستويين تنقّل**، والتفصيل لوحة جانبية أو صفحة برجوع. زر الرجوع دايماً بنفس المكان.
4. **أي قائمة فوق 7 بتنطوي** («عرض الكل (n)»). أي صفحة فوق 3 شاشات لازم تنقسم أو تنطوي.
5. **كل زر بيعمل شي حقيقي** أو ما بيظهر.
6. **الردّ فوري:** الضغطة بتبيّن خلال 100ms. النتيجة خلال ثانية، أو هيكل تحميل. الفعل اللي بينرجع بيتنفّذ فوراً ومعه «تراجع» 5 ثواني.
7. **نفس الشي بنفس الشكل** بكل مكان (القرار، المهمة، الرقم، الحالة).
8. **الحالة بالرابط:** التبويب والفلتر واليوم بالعنوان، فالرجوع والمشاركة بيرجّعوا نفس الشاشة.
9. **الجوال أول:** كل شاشة بتنرسم على 375 أول. أهداف اللمس 44px. الجداول بتصير بطاقات. اللوحات من تحت.
10. **ولا تمرير أفقي** على 375 إلا جوّا جدول معلَن.
11. **الحركة للمعنى بس:** 150ms `ease-out` للّوحات والقوائم. `prefers-reduced-motion` بيطفّيها. ولا حركة زينة.
12. **الطباعة:** خريطة المهام، التقرير، ورقة القرار، وأرقام اليوم إلهم نسخة A4 (متل عيّنتك).

## 8. الكلمات

لغة الواجهة عامية أردنية/سورية بسيطة. الكلمات هاي ممنوعة بوجه المستخدم (مسموحة جوّا «متقدّم» وبالكود):

| ممنوع | البديل |
|---|---|
| ورك فلو · workflow | مهمة مجدولة (والقائمة: «الشغل») |
| خطوة · node | فرع |
| handoff · تسليم | متوقفة — بدها حدا يكمّلها |
| ChangeSet | تغيير |
| dry-run | تجريبي (ما بينبعت لميتا) |
| MCP · API · webhook · token | ربط Claude · ربط · مفتاح |
| CAPI | إرسال الطلبات لميتا |
| executor | مين بينفّذ |
| approval | موافقة / قرار |
| KPI · dashboard | رقم · لوحة |

كل مكان إله جملة «شو هاي الصفحة» و«الخطوة الجاية» بـ `src/lib/guide.ts` (بتنكتب من جديد للأماكن الخمسة). كل رقم بيضل بشارة مصدره و«ليش؟» (`src/lib/glossary.ts`).

## 9. إمكانية الوصول

تباين AA لكل نص · حلقة تركيز ظاهرة على كل عنصر تفاعلي · كل أيقونة-زر إلها `aria-label` بالعربي · الحالة مش باللون لحاله (شارة فيها كلمة، مش نقطة بس) · `dir="rtl"` والخصائص المنطقية (`ms-`/`me-`/`inset-inline`) · التبويبات روابط حقيقية بتشتغل بالكيبورد.
